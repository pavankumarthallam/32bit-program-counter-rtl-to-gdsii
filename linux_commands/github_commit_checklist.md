# GitHub commit checklist

Before committing this folder to the Program Counter repository:

- [ ] Place this directory at the repository root as `linux_commands/`.
- [ ] Check that the README links point to existing files.
- [ ] Confirm commands marked as recorded are supported by the project history.
- [ ] Keep suggested/example commands clearly labeled.
- [ ] Remove local machine-specific secrets or tokens (none should be needed here).
- [ ] Do not include the full ORFS installation, PDK, caches, or huge build directories.
- [ ] Review that paths use `~` or explicit placeholders rather than assuming another user's home directory.
- [ ] Commit with a descriptive message such as `docs: add Linux and ORFS command reference`.
